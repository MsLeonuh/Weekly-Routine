# My Week

A personal weekly routine tracker with a Monaco old money look: ivory, navy and gold.

## What it does

- Day-by-day checklist, Monday to Sunday
- Water tracker with a 2L daily goal
- Weekly progress bar
- Busy week mode that cuts the routine down to the core items
- Resets automatically every Monday

## How to use it

Open the live page, tap a day, and tap a task to check it off. Tap the cups to log water. Switch to Busy week mode whenever the week gets hectic.

## How to edit the routine

Open the HTML file and find the list that starts with `const TASKS=[`. Each line is one task. Change the name, the time note, or the days it shows up on (0 is Monday, 6 is Sunday). Add `core:true` to keep a task in Busy week mode.

## Notes

Progress is saved in your browser on each device, so your phone and laptop won't sync with each other.
